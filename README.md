# Lombardy: law as git history

Work in progress. This repository will hold the law of Lombardy (Regione Lombardia, Italy) as a git history: one file per
article, one commit per change, on the day it took effect, `git blame` and `git log` working line by line.

Planned first build: the Statute (Statuto), then the regional laws in force.

Source: Consiglio regionale della Lombardia, Banca dati NormeLombardia, <https://normelombardia.consiglio.regione.lombardia.it/>.
